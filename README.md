# AI 全栈开发指南

一本面向工程师的开源、实践导向的 AI 全栈开发书。

> 从后端工程视角出发，把 AI 应用真正做成能稳定运行在生产环境里的系统。

---

## 这本书在讲什么

**AI 全栈**，在我们的语境里指的是把 AI 能力从
「跑通一个 Demo」推进到「一套可上线、可观测、可迭代的系统」所需要的完整工程能力：

```
模型接入与推理服务  →  检索与 RAG 链路  →  Agent 编排
        ↓                      ↓                 ↓
    网关 / 鉴权 / 限流  →  可观测性与评测  →  部署与成本控制
```

全书以前后端都写过真实服务的人为读者，不假设你做过大模型训练，也不假设你是算法出身。

## 适合谁读

- **后端工程师**：有 Go / Java / Python 服务端经验，想转向 AI 方向
- **全栈工程师**：想把模型能力接进自己的产品，而不是停留在调 API
- **AI 应用开发者**：已经能写出 Demo，但要解决它在真实流量下的稳定性问题

## 不太适合谁

- 想深造模型训练、微调、论文复现的读者（本书不覆盖训练向内容）
- 完全零编程基础的读者
