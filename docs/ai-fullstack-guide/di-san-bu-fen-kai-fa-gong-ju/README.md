# 第三部分 · 开发工具

工具决定你干活的速度，也决定你的活能不能被别人接手。这部分不追新，只看四个问题：**它解决什么问题、代价是什么、什么团队该用、什么时候该换。**

## 四个工具，各管一件事 🧰

| 工具     | 解决的问题        | 不解决什么     |
| ------ | ------------ | --------- |
| 模型     | 生成、理解、推理     | 业务规则、数据权限 |
| IDE    | 你写代码的速度      | 代码质量和上线安全 |
| MCP    | 模型怎么安全地碰外部系统 | 提示词质量     |
| SKILLS | 重复任务怎么固化     | 新问题怎么决策   |

{% hint style="warning" %}
工具会换，换得很快。这部分真正想让你带走的是「**怎么判断一个工具值不值得引入**」：它替掉了什么重复劳动？出错时谁能发现？换掉它的成本是多少？
{% endhint %}
