# AI 全栈开发指南

一本面向工程师的开源、实践导向的 AI 全栈开发书。

> 状态：草稿 · 持续更新。GitHub 仓库：[haiqit/ai-fullstack-guide](https://github.com/haiqit/ai-fullstack-guide)

## 这本书想解决什么

大多数 AI 教程停在「能跑通一个 Demo」，而生产系统要回答的是另一组问题：延迟能不能接受、成本能不能算清、出错之后服务会不会雪崩、出了问题怎么定位。本书从后端工程视角出发，把这些问题的答案整理成可以复用的方法与取舍。

## 怎么读

* **第一部分**先建立能力地图，回答「AI 全栈到底包含哪些层」。
* **第二到第五部分**按链路展开：推理服务、RAG、Agent、工程化。每部分都可以单独阅读。
* **第六部分**是两个完整项目，用来把前面的知识点串起来。

## 关于示例代码

代码以 Python 为主。需要和传统后端习惯对照的地方，会给出 Go 的类比，因为本书作者的生产经验主要来自 Go 服务端。
