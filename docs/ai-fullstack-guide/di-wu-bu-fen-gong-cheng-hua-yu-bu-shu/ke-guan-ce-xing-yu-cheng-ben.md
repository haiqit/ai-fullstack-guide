# 可观测性与成本

## 一条请求应该记录什么

* trace id、用户/租户
* 模型名与版本
* 输入 token、输出 token
* 首 token 延迟、总延迟
* 是否重试、是否命中缓存、是否降级

## 成本怎么算

```
单次成本 = 输入 token × 输入单价 + 输出 token × 输出单价
```

按租户、按接口、按模型分别聚合，才能回答「钱花在哪」。

## 质量监控

* 定期抽样人工评测。
* 收集用户反馈（点赞/点踩/重问率）。
* 对关键指标设告警，而不是等用户投诉。

## 一个提醒

成本优化最有效的手段通常不是换更便宜的模型，而是**减少无效上下文**。
