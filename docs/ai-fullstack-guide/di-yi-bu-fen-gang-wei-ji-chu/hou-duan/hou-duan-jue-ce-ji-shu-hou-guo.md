# 后端决策 → 技术后果：映射表

左边是后端常见决策，中间是对前端、运维的后果，右边是评审时该问的问题。

```mermaid
flowchart LR
    A["⚙️ 后端决策<br/>分页 · 幂等 · 错误码 · 租户"] --> B["🖥️ 前端后果<br/>要写适配、要处理重试"]
    A --> C["🛠️ 运维后果<br/>要扩容、要兜底"]
    B -.->|"验收不过"| D["📋 该问什么<br/>当场定"]
    C -.->|"事故复盘"| D
```

## 怎么用 📋

技术方案评审时，**从上到下过一遍左列**。命中的那几行，把右列的问题当场问出来，前后端和运维一起对答案。

{% hint style="success" %}
这张表真正值钱的是**中间两列**。「后端用什么分页」谁都会争；「offset 分页会让无限滚动出现重复数据」这句话拿出来，争议就结束了。
{% endhint %}
